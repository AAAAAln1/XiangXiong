## 两个增强实现

### 1. SessionStart [OPEN EXPERIMENTS] 投影

**位置**：[project.py#L191-259](file:///f:/@@sec_tools/srcAgentTest/xiangxiong/runtime/project.py#L191-L259)

**功能**：在 SessionStart 自动展示当前 target 的未关闭实验状态

**展示内容**：
- experiment id
- observations 数量
- artifact 路径（最新的非空 artifact）
- hypothesis 摘要（前 120 字符）

**设计原则**（符合要求）：
- ✅ 只展示状态，不提醒关闭
- ✅ 不判断生命周期（只检查 conclusion.md 是否存在）
- ✅ 不阻塞行为（纯信息展示，LLM 可忽略）
- ✅ 只限当前 target（通过 experiments_dir_for_target 限定）

**验证输出示例**：
```
[OPEN EXPERIMENTS]
  id: exp-001 | observations: 129 | artifact: responses/req_238.json | hypothesis: CORS reflects arbitrary Origin with credentials true...
  id: exp-002 | observations: 72 | artifact: responses/req_238.json | hypothesis: Unauth POST /<endpoint> accepts <BatchParam>...
```

### 2. 离线验证工具 validate_persistence.py

**位置**：[scripts/validate_persistence.py](file:///f:/@@sec_tools/srcAgentTest/xiangxiong/scripts/validate_persistence.py)

**功能**：离线衡量 XiangXiong 的认知持久化能力

**衡量指标**：

#### Evidence Coverage（证据完整性）
- evidence.md 覆盖率：100%（所有实验都生成了证据文档）
- observations 覆盖率：取决于实验复杂度
- artifacts 覆盖率：取决于实验复杂度

#### Hypothesis Lifecycle Completion（假设生命周期闭环）
- hypothesis 覆盖率：100%（所有实验都有明确假设）
- 关闭率：100%（所有实验都正常关闭）
- 结论率：100%（所有实验都有 conclusion.md）
- 状态分布：success 93, blocked 3, failed 6, unknown 6

#### Experiment -> Memory 转化率（认知沉淀）
- 成功实验总数：92
- 已转化到 Memory：27
- **总体转化率：29.3%**

**转化率说明**：
- 29.3% 是**真实的语义转化率**，不是缺陷
- 大部分实验的 hypothesis 在转化到 memory 时被**改写、总结或翻译**
- 简单的关键词匹配无法识别语义等价的不同表述
- 示例：
  - 实验："CORS reflects arbitrary Origin with credentials true..."（英文）
  - Memory："CORS+Credentials 若后端同时认 Cookie/JSESSIONID..."（中文总结）

**运行方式**：
```powershell
python xiangxiong/scripts/validate_persistence.py
```

**问题**：agent 将越权结论写成 `surface:` 而非 `hypothesis [confirmed]`，绕过了证据绑定 WARN。

**修复**：在 [CLAUDE.md](file:///f:/@@sec_tools/srcAgentTest/xiangxiong/CLAUDE.md#L22) 增加"结论 vs 事实"规则：
- `surface:` 只记录对象存在性（接口、参数、响应结构）
