# Evidence Model

Observation != Fact。观察是特定请求上下文和来源层产生的结果，必须保留对应 artifact 与来源，并容纳替代解释。事实是观察在明确边界内能够支持的陈述，不得超出来源与上下文。

观察链可能经过执行器、网络、边缘层、网关、应用与后端；任一层都可能产生、改写、截断或隐藏结果。工具成功或失败首先是工具链事实，只有来源可区分时才能约束目标世界。摘要不是完整证据，未显示的 Artifact 内容仍可能包含更早出现的对象和关系。

孤立响应通常弱于受控差分。Baseline 与只改变一个相关条件的 Mutation 之间若产生稳定、可追溯差异，可以缩小替代解释；无差异只约束本次上下文与变量范围，不证明所有路径等价。

例如 403 可由 WAF、Gateway、App auth 或 route concealment 产生；这些只是替代解释，不是裁决。单次结果不能自动产生 `surface:`、`dead:` 或 `vuln:`。证据强度来自观察、来源和解释之间可追溯、可区分的联系，而不是标签、状态码或重复次数本身。
